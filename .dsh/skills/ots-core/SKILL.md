# SKILL · ots-core (параметрическая общая теория систем)
<!-- sources: .dsh/skills/ots-core/SKILL.md -->
<!-- synced: 20261106 (imported from project skills by format migration) -->



Автономный скилл для формирования системных данных: описания объектов, построения моделей, классификации, оценки. Основан на параметрической ОТС (А.И. Уёмов, И.Н. Сараева, А.Ю. Цофнас. «Общая теория систем для гуманитариев», 2000). Самодостаточен — читается без внешних источников.

## 0. Когда применять
- Нужно описать сложный объект (технический, социальный, текстовый) как систему.
- Нужно дать строгое определение понятия без «круга в определении».
- Нужно классифицировать объекты по системным признакам.
- Нужно оценить систему по параметрам (центрированность, сложность, целостность).
- Нужно формализовать качественное суждение (без числовых измерений).

## 1. Базисные категории (функциональные, не абсолютные)
Категории безразличны к природе объекта и различаются по функции в суждении.

| Категория | Роль в суждении | Пример |
|---|---|---|
| **Вещь** | подлежащее (то, о чём говорится) | «стекло», «Портос», «Кобзарь» |
| **Свойство** | приписывается вещи, не меняет её | «прозрачность», «высокий рост» |
| **Отношение** | связывает вещи, образует новую вещь | «брат Петра», «пара туфель» |

Правила:
- Одна и та же сущность может быть вещью, свойством или отношением — зависит от функции. «Равенство» — вещь (лозунг), свойство (человек свободен и равен), отношение (граждане равны перед законом).
- Свойство не меняет вещь; отношение — образует новую вещь (пара туфель ≠ две туфли по отдельности).
- Не путать «тело» (физическое, пространственное) и «вещь» (качественное, по совокупности свойств). Одно тело может нести разные вещи; одна вещь — реализоваться в разных телах («Кобзарь» в разных изданиях).

## 2. Определение системы (атрибутивный концепт)
Система задаётся тремя дескрипторами:
- **Концепт (P)** — заранее фиксированное свойство, которое должно реализоваться.
- **Структура (R)** — отношение (отношения), обладающее этим свойством.
- **Субстрат (m)** — объект(ы), на котором реализуется структура.

Формула (компактная): `(tA)Sist =df ([a(*tA)])t`
Словесно: **«Любой объект является системой по определению, если в этом объекте реализуется какое-то отношение, обладающее определённым (заранее заданным) свойством».**

Двойственное определение (реляционный концепт): `(tA)Sist =df t([(tA*)a])` — «в объекте реализуются какие-то свойства, находящиеся в заранее заданном отношении».

Принципы:
- **Универсальность**: любой объект можно представить как систему (относительно подходящего концепта).
- **Относительность**: вещь, системная по одному концепту, может не быть системой по другому. Это объективно, не субъективно.
- **Дополнительность**: атрибутивная и реляционная модели дополняют друг друга (аналог корпускулярно-волнового дуализма). Полное описание — обе модели.

## 3. Требования к определению
1. Нет «круга в определении»: дефиниенс не содержит определяемого слова или его однокоренных.
2. Не слишком широкое: позволяет отделить системы от не-систем.
3. Не слишком узкое: не исключает объекты, которые обязаны быть системами.
Если определение слишком узкое — ищи **инвариант** (общую неизменную часть) и формулируй через него.

## 4. Атрибутивные системные параметры (оценка системы «самой по себе»)
Каждый параметр — основание деления систем на классы. Значения задаются относительно дескрипторов.

### 4.1. Бинарные (два значения)
| Параметр | Значения | Смысл |
|---|---|---|
| Расчленённость | расчленённая / нерасчленённая | есть ли у субстрата чэпсы (части/элементы) |
| Завершённость | субстратно завершённая / открытая | можно ли добавить элемент без разрушения |
| Имманентность | имманентная / неимманентная | охватывает ли системообразующее отношение только элементы системы |
| Минимальность | минимальная / неминимальная | разрушается ли при удалении любого элемента |
| Центрированность | центрированная / нецентрированная (внутр./внешн.) | есть ли центр, через который опосредуются все отношения |
| Цепность | цепная / нецепная | каждый элемент связан не более чем с двумя другими |
| Опосредование | с опосредованием / без | участвует ли элемент в структуре напрямую или через другие |
| Детерминированность | детерминирующая / недетерминирующая | предопределяет ли наличие одних элементов наличие других |
| Стационарность | стационарная / нестационарная | сохраняется ли при замене элементов |
| Стабильность | стабильная / нестабильная | сохраняется ли при изменении структуры |
| Надёжность | всецелонадежная / невсецелонадежная | сохраняется ли при удалении любого числа элементов (кроме одного) |
| Регенеративность | авторегенеративная / внешнерегенеративная | восстанавливает ли элементы сама или с помощью извне |
| Вариативность | вариативная / невариативная | есть ли состояния (иные отношения, кроме системообразующего) |
| Сила | сильная / слабая | меняет ли вхождение в систему свойства элементов |
| Уникальность | уникальная / неуникальная | реализуется ли структура только на данном субстрате |
| Гомогенность | гомогенная / гетерогенная | однородны ли элементы (по субстрату или структуре) |

### 4.2. Линейные (множество значений, измеримы)
- **Сложность**: структурная (разнообразие отношений, энтропийная мера Шеннона) и субстратно-структурная (разнообразие отношений на каждом элементе). Чем больше разнообразие — тем сложнее.
- **Целостность**: степень связности; типы — концептуальная, структурная, субстратная и их комбинации. Измеряется по шкале связных списков (выводимость формул связности в ЯТО).

## 5. Реляционные системные параметры (отношения между системами)
- **Изоморфизм** — совпадение систем по структуре (взаимно-однозначное соответствие с обратимым «переводом» отношений).
- **Гомоморфизм** — соответствие только в одну сторону (не симметрично).
- **Совпадение по субстрату**: полное / частичное / полное исключение.
- **Функциональное различие**: структура одной системы как субстрат другой и т.п.
Универсальность: между любыми системами найдётся отношение, являющееся значением реляционного параметра (потому что любые объекты можно представить как системы).

## 6. ЯТО (язык тернарного описания) — минимальный рабочий набор
- **t** — определённый объект («этот»); **a** — неопределённый («какой-то», «первый попавшийся»); **A** — произвольный («любой»).
- **Круглые скобки**: `(A)B` — «объект A имеет свойство B»; `B(A)` — «объект A имеет отношение B». Символ справа от скобок — свойство, слева — отношение, внутри — вещь (позиционный принцип).
- **Звёздочка**: `(B*)A` — инверсная формула, «свойство B присуще объекту A» (движение мысли от свойства к предмету).
- **Квадратные скобки** — замыкание: `[A]` превращает пропозициональную формулу в концептуальную (понятие).
- **Йота-оператор** (ι или 1) — тождество: одинаковый оператор перед символами означает, что речь об одном и том же объекте.
- **Импликации**: атрибутивная `A ⇒ B` (A тождествен объекту со свойством B), мереологическая `A ⊃ B` (A — часть/элемент/подмножество/свойство B), нейтральная `A → B` (обобщение обеих).
- **Валентность**: S — истинно, N — ложно, {S,N} — амбивалентно; нейтральная формула — без оценки.
- **Производные объекты**: `t′` — отличный от t; чэпса — часть/элемент/подмножество/свойство (строго отлична от объекта); подобъект — может совпадать с объектом; надобъект — расширение; диспарат — несовместимый с t.

Правила работы:
- ППФ (правильно построенная формула) не обязана быть истинной.
- Позиция символа задаёт его категорию (вещь/свойство/отношение) — не нужно разных начертаний.
- Для формализации качественных суждений достаточно этого набора; числовая математика не требуется.

## 7. Общесистемные закономерности (примеры для прогноза)
Эмпирические (вероятностные) и аналитические (доказуемые в ЯТО). Примеры:
- Если система авторегенеративна по элементам — она, как правило, авторегенеративна и по отношениям.
- Если система авторегенеративна по элементам — она, как правило, стационарна и стабильна по структуре.
- Если система внешнерегенеративна по элементам — она, скорее всего, внешнерегенеративна и по отношениям.
- Если система не внешнерегенеративна — она обычно невсецелонадежна.
- Система, как правило, обладает либо авторегенеративностью по отношениям, либо внешней регенеративностью по отношениям (редко обеими).
- Всякая субстратно-открытая система является неуникальной (аналитическая теорема).
- Всякая всецелонадежная система является неминимальной и неуникальной.
- Все системы с опосредованием — расчленённые, неминимальные, неуникальные.
- Внешнецентрированные системы неминимальны и неуникальны.

Применение: при прогнозе выбирай закономерность по известным значениям параметров; вероятность (q) — мера уверенности, не гарантия.

## 8. Порядок формирования системных данных (алгоритм)
1. **Зафиксируй концепт** — какое свойство/цель делает объект системой. Без концепта системы нет.
2. **Определи структуру** — какое отношение обладает этим свойством (реляционная структура).
3. **Определи субстрат** — на каких элементах реализуется структура.
4. **Проверь определение** на «круг», ширину, узость (см. §3).
5. **Опиши объект как систему**: дескрипторы + (при необходимости) атрибутивная и реляционная модели (принцип дополнительности).
6. **Определи значения системных параметров** относительно дескрипторов (§4, §5).
7. **Сформулируй закономерности/прогноз** на основе значений (§7).
8. **Формализуй** ключевые суждения в ЯТО (§6), если нужна строгость.

## 9. Чек-лист перед выдачей данных
- [ ] Указан концепт (не путать концепт с элементом субстрата).
- [ ] Определение не содержит круга.
- [ ] Определение не слишком широкое/узкое.
- [ ] Разведены вещь/свойство/отношение по функции.
- [ ] Указаны все три дескриптора (P, R, m).
- [ ] Значения параметров даны относительно дескрипторов (не «порядок вообще», а «порядок по такому-то концепту»).
- [ ] Если вывод опирается на закономерность — указана её вероятность.
- [ ] Если нужна строгость — суждение формализовано в ЯТО.

## 10. Частые ошибки (антипаттерны)
- «Система — это целостное множество элементов» — круг (целостность через систему) и слишком широко. → Задай концепт и структуру явно.
- «Порядок — это когда всё упорядочено» — тавтология. → Порядок = структура системы, удовлетворяющая заданному концепту; относителен к концепту.
- «Солнечная система центрирована» — зависит от концепта. По концепту «взаимодействие (тяготение)» — нецентрированная; по концепту «закономерность движения» — центрированная. → Сначала дескрипторы, потом параметр.
- «Любое свойство — свойство какого-нибудь отношения» — выводимо из аксиомы «всякая вещь есть отношение каких-то вещей», но противоречит интуиции языка. → Доверяй выводу из принятых аксиом, но фиксируй, какие аксиомы приняты.
- Смешение относительности и субъективности: скорость относительна (к системе отсчёта), но объективна; системность относительна (к концепту), но объективна. → Не путай «относительно концепта» с «как кому кажется».
